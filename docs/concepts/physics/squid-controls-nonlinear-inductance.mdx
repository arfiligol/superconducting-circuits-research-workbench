# Why can SQUID control nonlinear inductance values?

The reusable DC-SQUID phase constraint, effective Josephson energy, small-signal
inductance, asymmetry, and loop-inductance limits are owned by the SCQ_Design
Knowledge Base:

- [Canonical knowledge: DC-SQUID Flux Tunability](https://github.com/arfiligol/SCQ_Design/blob/main/docs/knowledge/josephson-physics/dc-squid-flux-tunability.qmd)
- [Prerequisite: Josephson Current, Phase, Energy, and Inductance](https://github.com/arfiligol/SCQ_Design/blob/main/docs/knowledge/josephson-physics/josephson-current-phase-energy-and-inductance.qmd)
- [Prerequisite: Fluxoid and Flux Quantization](https://github.com/arfiligol/SCQ_Design/blob/main/docs/knowledge/superconductivity/fluxoid-and-flux-quantization.qmd)

The current Python fitting surrogate does **not** implement flux-tunable
DC-SQUID physics. It accepts `L_jun` as the small-signal inductance of each of
two identical junctions and uses their parallel combination,
`L_sq = L_jun / 2`.

Workbench-specific consumers are:

- [SQUID Fitting](../../workflows/fem-result-to-equivalent-circuit/squid-fitting.mdx)
- [Flux Dependence Analysis](../../workflows/fem-result-to-equivalent-circuit/flux-analysis.md)
- [Notebook Interface](../../reference/notebooks/index.md)

Do not infer flux, critical current, junction asymmetry, bias phase, or loop
self-inductance from that surrogate. Use the canonical node for those semantics.
