# Floating Qubit Admittance Extraction

This page owns a Workbench workflow, not reusable network theory. The intended
output is a differential-mode driving-point admittance $Y_{in,dm}(\omega)$
whose coordinate normalization, compensated shunts, retained loads, and source
artifact are all visible.

## Current executable route

- `notebooks/pluto/includes/port_matrix_post_processing.jl` owns the matrix
  stack, declared shunt subtraction, real coordinate transform, and Kron solve.
- `notebooks/pluto/02_floating_lc_xy_line.jl` owns the executable example,
  local capacitance-derived weights, plots, and sanity checks.

The current notebook performs this concrete sequence:

```text
raw port-basis Y artifact
-> subtract declared probe shunts in the port basis
-> transform Pad1/Pad2 into common/differential coordinates
-> eliminate common and XY coordinates with zero external injection
-> inspect Yeff for the retained differential coordinate
```

That order matches the current API and keeps each declared probe shunt easy to
identify. It is not a universal theorem that compensation must precede the
coordinate transform: the operations are equivalent when the compensation
matrix is transformed consistently with $Y$.

## Current local convention

Notebook 02 maps ordered input labels `1, 2, 3` to `common, differential,
xy`. Its local differential voltage is $V_1-V_2$; its common-coordinate
weights are derived from the notebook's declared Pad-to-ground and Pad-to-XY
capacitances and sum to one. The notebook publishes both weights and the exact
matrix used at runtime.

The canonical [Admittance Coordinate Transforms](https://github.com/arfiligol/SCQ_Design/blob/main/docs/knowledge/network-modeling/admittance-coordinate-transforms.qmd)
page owns the dual-current derivation and power-pairing contract. They are not
duplicated here. This local normalization changes the numerical value of
$Y_{in,dm}$ and is not yet approved as a project-wide floating-qubit
convention.

## Current executable evidence

The notebook now publishes:

- the admittance quantity and raw-to-PTC-to-coordinate-to-Kron source lineage;
- exact input/output labels, transform matrix, local weights, and keep/drop
  partition;
- compiled evidence that ports 1 and 2 are the only compensated probe shunts
  and that the port-3 adapter shunt remains in the matrix, without claiming it
  is already a proven physical environment;
- full-sweep zero-external-injection and retained-response reconstruction
  residuals; and
- the eliminated-block 2-norm condition series, numeric type, coordinate basis,
  range, and worst frequency.

The condition series is evidence for a Human decision. The helper and notebook
do not choose a near-singular acceptance threshold.

## Required evidence

Before this workflow can produce design authority, record:

1. the raw $Y$ artifact, solver, port order, units, and provenance;
2. proof that every subtracted $1/R_i$ is an explicit parallel shunt in that
   artifact rather than only an $S$-parameter reference impedance;
3. the exact $A$ matrix and voltage/current normalization;
4. which environment loads remain in $Y$;
5. retained and eliminated labels for the Kron boundary; and
6. a raw-versus-processed comparison, singular diagnostics, the full condition
   series, and a Human-approved threshold for the intended use.

<Aside type="caution" title="Not yet a canonical floating-qubit result">

The capacitance-derived automatic $\alpha,\beta$, HFSS reference-plane and
loading comparison, and the mapping from $\operatorname{Re}Y_{in,dm}$ to a

page `draft`; do not promote its output into a reviewed physical parameter.

</Aside>
