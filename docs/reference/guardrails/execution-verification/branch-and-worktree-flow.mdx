# Branch & Worktree Flow

This page is a thin host profile selector, not an independent GitFlow
authority.

## SCQ_Design Host

Under SCQ_Design, load `$scq-collaboration-roles`. Circuit Workbench's
delivery-profile identifier is `standard-topic-pr`.

Read checkout, branch/worktree, commit-publication, PR, merge, target
verification, pin/synchronization, and cleanup mechanics from that canonical
profile.

## Other Hosts

Use the readable host's declared collaboration and delivery authority. If it
does not define one, this adapter grants no Git permission; preserve existing
bytes and obtain the missing authority before choosing a delivery path.
